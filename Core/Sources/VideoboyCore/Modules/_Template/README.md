# _Template

The canonical copy-me module (SPEC §1.5).

Copy this folder, rename `ExampleNode`, and fill in the four places marked in its
header comment:

1. `kind` — source, effect, mix or output
2. `parameters` — what it exposes, by **stable param code** (SPEC §13)
3. `latencyInFrames` — so the scheduler can compensate
4. `render` — the actual work

Plus `applyParameters(from:)` by convention, which is how a MIDI knob, an LFO, an
audio tap and a loaded template all reach the node by the same route.

Do not edit this file to build a feature. It exists to be read by whoever writes the
next module, and it should stay boring.

The worked example in `docs/ADD-A-MODULE.md` uses the DV corruptor, which is the one
module whose shape is worth studying: it is a pure byte transform, deterministic from
a seed, and it runs *before* decode.
