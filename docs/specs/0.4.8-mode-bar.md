# 0.4.8 — Mode bar, Settings mode, setup assistant

Plan of record: `docs/PROPOSAL-2026-09-26.md` §4 (mode bar), §8 (setup assistant), §9
(phase 2). Decisions there are final (⌘1 Import · ⌘2 VJ · ⌘3 Settings; SD NTSC 29.97
default). This spec is the build contract.

## Flag
`FeatureFlag.modeBar` (Core), **off by default** in 0.4.8 — Import mode is a placeholder
until 0.4.9. `VIDEOBOY_FLAGS=modeBar` turns it on. Flag off = the app is byte-for-byte
the 0.4.7 layout (22 pt strip, no View menu mode items, ⌘, opens the Preferences window,
first-run save-location reminder unchanged).

## Rules
- **Switching modes never touches the engine.** No stop, pause, rebuild or reload — it
  only hides views. Output and recording keep going; hidden VJ previews stop presenting
  (existing "skip presenting while not visible" behaviour).
- **VJ mode is SPEC §14 / layout-v6.** The only change is the strip: 22 → 32 pt.
- Real AppKit controls: `NSSegmentedControl`, `NSMenuItem` key equivalents, `NSPopUpButton`,
  `NSPathControl`/buttons, sheet via `beginSheet`. No modals from the assistant.
- Unbuilt parts (canvas choices other than SD NTSC, Optimize presets, Import mode body)
  render **disabled with a label**, never omitted.

## Self-QA `modes` (new, in `selfqa.sh`, not in verify) — asserts
1. Flag-on strip is 32 pt; flag-off strip is 22 pt.
2. **No performance control moves except by the strip change:** every control in the
   toolbar and grid of a flag-on shell at W×H has the same window-space frame as in a
   flag-off shell at W×(H−10), at three window sizes.
3. The mode bar's three segments are hit by `window.contentView.hitTest` at their
   centres (real window), and a hit-tested click switches mode.
4. View menu has Import/VJ/Settings with ⌘1/⌘2/⌘3; performing each switches mode.
5. In Import and Settings modes the grid is hidden and the mode view is visible; back
   to VJ restores the grid with identical control frames.
6. **Output never interrupted:** a live window with 4 channels playing; modes switched
   every 0.5 s for 10 s → render rate ≥ 29.5 fps, 0 dropped, no tick over 33.4 ms,
   and the engine's rendered-frame counter advanced every tick.
7. Settings mode embeds the Preferences panes (all 13 tabs present), Project shows SD
   NTSC 29.97 selected and the other canvases disabled.
8. Setup assistant: Continue through every page on defaults ends with `setupCompleted`
   true and the locations written to a scratch preference store; it never calls
   `runModal` (`NSApp.modalWindow == nil` throughout).
