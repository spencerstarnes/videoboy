- **Retro Emulation Library with TAS Support** — Build in MIT/BSD licensed emulators (NES, SNES, N64, PSX) as content sources alongside Amiga. Settings panel for ROM upload, with dedicated pane for TAS (Tool-Assisted Speedrun) file management. Extend the Amiga editor's state-save system to support emulation save/restore. Users upload ROMs + TAS instructions for playback in mixer as a new source type.
